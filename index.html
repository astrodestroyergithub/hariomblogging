ॐ हरि Blogging — Complete Admin Handbook, NeonDB Schema & Open CORS Developer APIs

This documentation is strictly hidden from public visitors so the public interface remains 100% natural and free of any technical details.

1. Netlify Hosting & Environment Variables Setup

When deploying the platform to Netlify, configure these three environment variables under Site Configuration → Environment Variables:

DATABASE_URL

Your NeonDB PostgreSQL connection string (postgresql://user:pass@ep-...neon.tech/neondb?sslmode=require).

ADMIN_USERNAME

Username required to unlock this Pradhan Sevak Portal and authenticate mutating POST/PUT/DELETE API requests.

ADMIN_PASSWORD

Secret password verified by netlify/functions/api.js via Basic Auth or X-HMB-Admin-Password headers.

2. Exposed Developer REST APIs & CORS Headers

All endpoints under /api/* (routed via netlify.toml to /.netlify/functions/api) include full CORS headers (Access-Control-Allow-Origin: *, Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS, Access-Control-Allow-Headers: Content-Type, Authorization, X-HMB-Admin-User, X-HMB-Admin-Password) so external apps and developers can consume your Dharmic content directly.

HTTP Method Endpoint Access Description
GET /api/posts?category=all&limit=20 Public (CORS *) Returns published Dharmic blog posts from hmb_blog_posts_tbl.
GET /api/posts/:slugOrId Public (CORS *) Fetches a single long-form discourse by slug or hmb_post_id.
POST /api/posts Admin Auth Creates a new discourse in hmb_blog_posts_tbl & writes audit log.
PUT /api/posts/:id Admin Auth Updates an existing discourse & triggers hmb_fn_touch_updated_at().
DELETE /api/posts/:id Admin Auth Deletes a discourse by ID/slug & logs action in hmb_admin_audit_log_tbl.
GET / POST / PUT / DELETE /api/quick-reads[/:id] Public GET / Admin Write Full CRUD for hmb_quick_reads_tbl Subhashita cards.
GET / PUT /api/config Public GET / Admin PUT Reads or updates global theme, language, festive banner & contact details.
GET /api/audit-logs Admin Auth Returns chronological audit history from hmb_admin_audit_log_tbl.

3. Unique hmb_ Prefixed NeonDB SQL Schema

Every database object uses the hmb_ prefix (hmb_site_config_tbl, hmb_blog_posts_tbl, hmb_quick_reads_tbl, hmb_festive_banners_tbl, hmb_contact_details_tbl, hmb_admin_audit_log_tbl, hmb_published_feed_vw, hmb_category_stats_vw, hmb_fn_touch_updated_at(), and hmb_trg_posts_updated_at) to guarantee zero naming conflicts in shared NeonDB instances. 

-- Unique 'hmb_' Prefixed NeonDB Schema (db/hmb_schema.sql)
CREATE TABLE IF NOT EXISTS hmb_site_config_tbl (
    hmb_config_id SERIAL PRIMARY KEY,
    hmb_config_key VARCHAR(120) UNIQUE NOT NULL,
    hmb_site_title VARCHAR(255) NOT NULL DEFAULT 'ॐ हरि Blogging',
    hmb_active_language VARCHAR(32) NOT NULL DEFAULT 'en',
    hmb_active_theme VARCHAR(64) NOT NULL DEFAULT 'sattvic_gold',
    hmb_active_festival_key VARCHAR(64) NOT NULL DEFAULT 'sharad_deepavali',
    hmb_banner_enabled BOOLEAN NOT NULL DEFAULT TRUE,
    hmb_banner_badge VARCHAR(120) NOT NULL,
    hmb_banner_headline VARCHAR(300) NOT NULL,
    hmb_banner_subtext TEXT NOT NULL,
    hmb_daily_mantra_sanskrit TEXT NOT NULL,
    hmb_daily_mantra_meaning TEXT NOT NULL,
    hmb_config_updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS hmb_blog_posts_tbl (
    hmb_post_id SERIAL PRIMARY KEY,
    hmb_post_slug VARCHAR(255) UNIQUE NOT NULL,
    hmb_post_title VARCHAR(400) NOT NULL,
    hmb_post_subtitle VARCHAR(600) DEFAULT '',
    hmb_post_category VARCHAR(120) NOT NULL,
    hmb_post_tags TEXT[] NOT NULL DEFAULT '{}',
    hmb_post_author_name VARCHAR(180) NOT NULL,
    hmb_post_author_role VARCHAR(180) NOT NULL,
    hmb_post_cover_image TEXT NOT NULL,
    hmb_post_shloka_sanskrit TEXT DEFAULT '',
    hmb_post_shloka_meaning TEXT DEFAULT '',
    hmb_post_excerpt TEXT NOT NULL,
    hmb_post_content_html TEXT NOT NULL,
    hmb_post_word_count INTEGER NOT NULL DEFAULT 0,
    hmb_post_char_count INTEGER NOT NULL DEFAULT 0,
    hmb_post_reading_minutes INTEGER NOT NULL DEFAULT 5,
    hmb_post_views_count INTEGER NOT NULL DEFAULT 108,
    hmb_post_likes_count INTEGER NOT NULL DEFAULT 27,
    hmb_post_is_featured BOOLEAN NOT NULL DEFAULT FALSE,
    hmb_post_is_published BOOLEAN NOT NULL DEFAULT TRUE,
    hmb_post_translations_json JSONB NOT NULL DEFAULT '{}'::jsonb,
    hmb_post_published_date DATE NOT NULL DEFAULT CURRENT_DATE,
    hmb_post_created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP,
    hmb_post_updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS hmb_quick_reads_tbl (
    hmb_quick_id SERIAL PRIMARY KEY,
    hmb_quick_title VARCHAR(300) NOT NULL,
    hmb_quick_category VARCHAR(120) NOT NULL,
    hmb_quick_sanskrit_verse TEXT NOT NULL,
    hmb_quick_summary TEXT NOT NULL,
    hmb_quick_scripture_source VARCHAR(200) NOT NULL,
    hmb_quick_reading_seconds INTEGER NOT NULL DEFAULT 90,
    hmb_quick_is_active BOOLEAN NOT NULL DEFAULT TRUE,
    hmb_quick_created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS hmb_contact_details_tbl (
    hmb_contact_id SERIAL PRIMARY KEY,
    hmb_contact_key VARCHAR(64) UNIQUE NOT NULL DEFAULT 'primary_sanctuary',
    hmb_sanctuary_name VARCHAR(250) NOT NULL,
    hmb_contact_email VARCHAR(200) NOT NULL,
    hmb_contact_phone VARCHAR(80) NOT NULL,
    hmb_contact_address TEXT NOT NULL,
    hmb_contact_hours VARCHAR(200) NOT NULL,
    hmb_social_x_handle VARCHAR(160) NOT NULL,
    hmb_social_youtube VARCHAR(160) NOT NULL,
    hmb_footer_blessing TEXT NOT NULL,
    hmb_contact_updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS hmb_admin_audit_log_tbl (
    hmb_audit_id SERIAL PRIMARY KEY,
    hmb_audit_action_type VARCHAR(100) NOT NULL,
    hmb_audit_entity_name VARCHAR(150) NOT NULL,
    hmb_audit_entity_ref VARCHAR(150) DEFAULT '',
    hmb_audit_summary TEXT NOT NULL,
    hmb_audit_payload_json JSONB NOT NULL DEFAULT '{}'::jsonb,
    hmb_audit_actor VARCHAR(120) NOT NULL DEFAULT 'pradhan_sevak',
    hmb_audit_created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE OR REPLACE VIEW hmb_published_feed_vw AS
SELECT hmb_post_id, hmb_post_slug, hmb_post_title, hmb_post_category, hmb_post_author_name,
       hmb_post_reading_minutes, hmb_post_views_count, hmb_post_likes_count, hmb_post_published_date
FROM hmb_blog_posts_tbl WHERE hmb_post_is_published = TRUE;
